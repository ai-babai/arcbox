# Arcbox 0.2.1

A visual fix for the application icon.

The project is now public under MIT, including Arcbox's original code and artwork. The bundled 7-Zip engine retains its separate licenses. Downloads no longer require repository access.

- Removed the mottled texture and dark smudges from the artwork.
- The sidebar and welcome screen now show the same icon as the macOS application.
- The running Dock icon is refreshed from the bundled artwork on launch.

Download **Arcbox-0.2.1-universal.dmg**, open it and drag Arcbox into Applications, replacing the earlier version. Quit the old version before launching the new one. The ZIP contains the same application. SHA256SUMS.txt verifies both downloads and release-info.json.

Requires macOS 14+. Universal Apple Silicon/Intel binaries; runtime checked on Apple Silicon. Ad-hoc signed, **not Apple-notarized**. If macOS blocks the first launch, follow the per-app [Apple instructions](https://support.apple.com/102445).
