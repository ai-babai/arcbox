# Arcbox 0.2.2

A more comfortable creation flow and a centered welcome screen.

- Format and compression share a row; password protection is enabled when needed.
- Source lists show a compact summary, and custom part sizes are entered inline.
- The sheet adapts to its content and available screen height. Cancel/Create remain visible outside the scroll area.
- The welcome group stays centered with the sidebar visible or hidden.
- Clean vector artwork, English/Russian UI, multipart archives, JSON CLI and MCP are included.

**Download:** open Arcbox-0.2.2-universal.dmg and drag Arcbox into Applications, replacing the earlier version after quitting it. The ZIP contains the same application. SHA256SUMS.txt verifies the downloads and release-info.json.

macOS 14+, Universal Apple Silicon/Intel. Runtime checked on Apple Silicon. Ad-hoc signed, **not Apple-notarized**; follow the per-app [Apple first-launch instructions](https://support.apple.com/102445) if blocked.

Public source and original artwork: MIT. Bundled 7-Zip retains its separate licenses.
