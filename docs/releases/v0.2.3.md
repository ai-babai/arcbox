# Arcbox 0.2.3

**English by default, with EN / RU always within reach.**

- A visible language switch in the toolbar, including the welcome screen.
- Compact native titlebar: Arcbox stays on the left, actions on the right.
- English is the default for fresh installations. Language choices are saved; View → Language also offers System.
- Resize both sidebar and inspector by dragging their dividers; widths and visibility are saved. Double-click a divider to reset its width.
- Both panels slide open/closed and respect Reduced Motion.
- Animated loading placeholders and a shared activity panel with operation labels, elapsed time and cancellation. No invented progress percentages.
- Includes the compact creation sheet, centered welcome screen, clean vector icon, multipart workflows and shared-core CLI/MCP.

Download **Arcbox-0.2.3-universal.dmg**, quit the earlier version, then drag Arcbox into Applications to replace it. ZIP contains the same app; verify the downloads with SHA256SUMS.txt.

macOS 14+, Universal Apple Silicon/Intel. Runtime checked on Apple Silicon. Ad-hoc signed, **not Apple-notarized**; use Apple's [per-app first-launch instructions](https://support.apple.com/102445) if blocked.

Public source and original artwork: MIT. Bundled 7-Zip retains its separate licenses.

## Русский

Переключатель EN / RU теперь виден справа в шапке: на главной и внутри архива. По умолчанию приложение запускается на английском, выбранный язык сохраняется. Язык системы можно явно выбрать через «Вид → Язык».

Включены компактная форма создания, стартовый экран по центру, чистая векторная иконка, части внутри основных действий, CLI и MCP.

Sidebar и инспектор теперь можно растягивать за разделитель. Ширина и видимость сохраняются; двойной щелчок сбрасывает ширину. Обе панели плавно открываются и закрываются, учитывая Reduce Motion.

Ожидание сопровождается анимированными заготовками списка и общей панелью операции с таймером и отменой. Переход к результату плавный, выдуманных процентов готовности нет.

Скачай Universal DMG, закрой старую версию и замени Arcbox в Applications. Нужна macOS 14+. Сборка без Apple notarization. Исходники открыты под MIT, скачивание без GitHub-аккаунта.
