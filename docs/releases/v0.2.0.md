# Arcbox 0.2.0

A native macOS archive manager with one workflow for ordinary and multipart archives, English/Russian UI, and a JSON CLI/MCP interface.

## Downloads

- **Arcbox-0.2.0-universal.dmg**: open and drag Arcbox to Applications.
- **Arcbox-0.2.0-universal.zip**: the same application as a ZIP.
- **SHA256SUMS.txt**: checksums for both downloads and release-info.json.
- **release-info.json**: exact source revision, architectures, signing status and validation scope.

Requires **macOS 14 or later**. Includes **Apple Silicon and Intel** executables and the archive engine. No Homebrew or developer tools are needed on the receiving Mac.

**Signing:** ad hoc, **not Apple-notarized**. On first launch, macOS may block the app. Verify the download, then use System Settings → Privacy & Security → Open Anyway for Arcbox. Do not disable Gatekeeper globally. [Apple's instructions](https://support.apple.com/102445).

## What's included

- Open any volume; Arcbox locates the first and sibling parts.
- Create ZIP/7z/TAR with optional multipart output and SHA-256 manifests.
- Extract directly from the set; raw file parts restore the original bytes.
- Missing or damaged parts produce actionable errors and Retry.
- Preset part-size slider, custom sizes, passwords, search, Quick Look and integrity checks.
- Smooth hide/show sidebar with Reduced Motion support.
- English and Russian, selectable in View → Language.
- Shared-core JSON CLI and six MCP stdio tools.

## Scope

Runtime checks were performed on Apple Silicon with macOS 15.8.1. Both architectures are included, but a physical Intel Mac has not been tested. This is an early release; it has not undergone an independent security audit.

RAR creation, in-place archive editing and recovery records are not implemented. A raw part set without its manifest cannot prove the last part is present. Extracted files and archive sources are never silently overwritten or deleted.

## Русский

Нативный архиватор для macOS 14+ с EN/RU, плавной боковой панелью и частями внутри «Открыть / Создать / Распаковать». Скачай DMG, открой его и перенеси Arcbox в Applications. ZIP содержит то же приложение.

Сборка универсальная: Apple Silicon и Intel. Она подписана локально, но **не нотарифицирована Apple**. При блокировке первого запуска проверь SHA-256 и используй штатное разрешение для Arcbox в «Конфиденциальность и безопасность». Глобально отключать Gatekeeper не нужно. Подробности: [русский README](https://github.com/ai-babai/arcbox/blob/main/docs/README.ru.md).
